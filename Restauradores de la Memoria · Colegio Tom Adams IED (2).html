¿Qué es Restauradores de la Memoria?

Es una iniciativa pedagógica donde estudiantes investigan, recuperan y documentan objetos, relatos y fechas significativas para construir memoria institucional. Este portal divulga su trayectoria, gestiona sus actividades y las proyecta digitalmente.

Base de datos y administración

Modelo relacional con 8 tablas. Aquí se simula en el navegador (localStorage); el script SQL equivalente está abajo y puede ejecutarse en MySQL/SQLite.

Visitantes registrados

Ver script SQL
CREATE TABLE Visitantes(id_visitante INTEGER PRIMARY KEY, nombre TEXT NOT NULL, correo TEXT NOT NULL, id_evento INT, comentario TEXT, fecha_registro DATE);
CREATE TABLE Eventos(id_evento INTEGER PRIMARY KEY, nombre TEXT, fecha DATE, lugar TEXT, descripcion TEXT);
CREATE TABLE Actividades(id_actividad INTEGER PRIMARY KEY, id_evento INT REFERENCES Eventos, titulo TEXT, tipo TEXT, responsable TEXT);
CREATE TABLE Objetos_Museo(id_objeto INTEGER PRIMARY KEY, nombre TEXT, descripcion TEXT, modelo_3d TEXT, foto TEXT, creditos TEXT);
CREATE TABLE Exposiciones(id_exposicion INTEGER PRIMARY KEY, titulo TEXT, fecha_inicio DATE, fecha_fin DATE);
CREATE TABLE Exposicion_Objeto(id_exposicion INT REFERENCES Exposiciones, id_objeto INT REFERENCES Objetos_Museo);
CREATE TABLE Evidencias(id_evidencia INTEGER PRIMARY KEY, id_actividad INT REFERENCES Actividades, tipo TEXT, url TEXT);
CREATE TABLE Aliados_Reconocimientos(id INTEGER PRIMARY KEY, nombre TEXT, tipo TEXT, descripcion TEXT, fecha DATE);
-- Consulta: visitantes por evento
SELECT e.nombre, COUNT(*) FROM Visitantes v JOIN Eventos e USING(id_evento) GROUP BY e.nombre;
